Cum Funcționează Aplicația

How the Application Works

PPT Finder simplifică fluxul de lucru hibrid combinând stocarea locală cu serviciile web.

PPT Finder simplifies your hybrid workflow by linking local storage file system with web scraping engines.

📂

1. Scanare & Indexare

1. Directory Scanning

La pornire, citește folderele setate în config.txt și extrage automat textul din slide-urile .pptx utilizând biblioteca nativă Python.

On startup, it parses the folders defined in config.txt, extracting text slides from all .pptx files using python-pptx.

⚡

2. Căutare Fuzzy Rapidă

2. Instant Fuzzy Search

Căutările sunt normalizate prin eliminarea diacriticelor și a diferențelor de litere mari/mici, returnând potriviri perfecte în sub 5ms.

Search queries are normalized (ignoring diacritics and casing), matching and filtering slides in under 5 milliseconds.

🌐

3. Integrare API Web

3. Online Lyrics Scraping

Dacă un cântec nu este găsit în calculator, interoghează automat baza de date Resurse Creștine online, formatează textul și îl afișează instant.

If a song is missing locally, it fetches lyrics from the Resurse Creștine database, parses them into stanzas, and displays them.

🖥️

4. Ecran Secundar & Mobil

4. Dual Screen & Mobile

Ecranul secundar al proiectorului rulează ca un tab fullscreen în browser și face polling automat pentru a proiecta instantaneu slide-ul selectat.

The secondary screen runs as a browser window in fullscreen mode, polling the backend state to project slides instantly.

Telecomandă mobilă: ce controlează

Mobile remote: what it controls

Pagina /remote controlează întotdeauna ultima sesiune selectată în PPT Finder.

The /remote page always controls the most recently selected session in PPT Finder.

📽️

Prezentare PowerPoint gestionată

Managed PowerPoint presentation

În rezultatele locale, apasă ▶ Open. Serverul deschide fișierul într-o instanță PowerPoint gestionată; telecomanda vede același fișier, slide-urile și poziția curentă.

In local results, press ▶ Open. The server opens the file in a managed PowerPoint instance; the remote sees that same deck, its slides, and its current position.

🎵

Resurse Creștine și proiecția web

Resurse Creștine and web projection

În rezultatele web, apasă 📺 Project. Strofele și refrenele devin o sesiune comună: telecomanda poate selecta direct versul, merge înainte/înapoi sau opri proiecția.

In web results, press 📺 Project. Verses and choruses become a shared session: the remote can select a verse directly, go next/previous, or stop projection.

📱

Conexiune în Rețea

Local Network Setup

  1. Asigură-te că laptopul și telefonul sunt pe aceeași rețea Wi-Fi.
  2. Connect the projector computer and your remote phone to the same Wi-Fi router.
  3. Deschide serverul pe calculatorul conectat la proiector.
  4. Launch the server on the laptop wired to your projector screen.
  5. Trage fereastra http://localhost:8080/projector pe monitorul secundar și apasă F11 pentru ecran complet.
  6. Drag the browser view of http://localhost:8080/projector onto the projector and press F11.
  7. Scanează codul QR sau deschide http://<IP-calculator>:8080/remote. Telecomanda controlează ultima prezentare PowerPoint deschisă cu ▶ Open sau ultima proiecție Resurse Creștine trimisă cu 📺 Project.
  8. Scan the QR code or open http://<computer-IP>:8080/remote. The remote controls the last PowerPoint deck opened with ▶ Open or the last Resurse Creștine projection sent with 📺 Project.

Întrebări Frecvente

Frequently Asked Questions

Aplicația are nevoie de Microsoft PowerPoint instalat? Does this application require Microsoft PowerPoint installed?
Nu pentru căutare, indexare sau proiecția de versuri web: fișierele .pptx pot fi citite cu biblioteci Python. Da pentru deschiderea și controlul unei prezentări PowerPoint reale din /remote; PowerPoint trebuie instalat pe calculatorul server. Not for search, indexing, or web-lyric projection: .pptx files can be read with Python libraries. Yes for opening and controlling a real PowerPoint presentation from /remote; PowerPoint must be installed on the server computer.
Funcționează fără conexiune la internet? Can I run this without internet access?
Da, funcționează perfect offline. Conexiunea la internet este utilizată doar dacă dorești să descarci automat versuri noi din baza de date Resurse Creștine. Yes, it works completely offline. Internet is only required if you perform searches for songs that aren't in your local folder and need to fetch them from the Resurse Creștine online database.
Telecomanda poate controla și cântecele din Resurse Creștine? Can the remote also control Resurse Creștine songs?
Da. După ce apeși 📺 Project pentru un rezultat web, strofele sunt trimise în sesiunea comună de proiecție. Pagina /remote se schimbă automat în modul Resurse Creștine și oferă aceleași comenzi de navigare și selectare directă. Yes. After you press 📺 Project for a web result, its verses are sent to the shared projection session. The /remote page automatically switches to Resurse Creștine mode and offers the same navigation and direct-selection controls.
